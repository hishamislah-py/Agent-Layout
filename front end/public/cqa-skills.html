Skills Catalog · 13 skills · 4 packages

The skills that run the assessment

The CQA pipeline is structured as four Claude skill packages. Each contains agent prompts, orchestration logic and scripts; skills invoke each other through the orchestrator, each running with model: inherit. Together they run the tools, normalise their output, recover structured evidence and build the report.

Packages  cqa-final-core / -tooling / -debt / -reverse Skills  13

Overview

How the packages fit together

cqa-final-core orchestrates the run, slices findings for each agent, gates tool failures and builds the final report. cqa-final-tooling dispatches the 20+ scanners, detects the tech stack and normalises every tool's output into one canonical schema. cqa-final-debt extracts accumulated technical-debt signals, and cqa-final-reverse produces the structured evidence files — DB analysis, user journeys, design recovery and deep coverage — that the dimension agents read alongside the raw findings.
