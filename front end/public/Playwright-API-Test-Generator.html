Overview

What it does

Given an API spec — OpenAPI/Swagger, Postman/Insomnia collections, curl, or a test-case sheet — the Playwright API Test Generator skill produces production-ready @playwright/test API suites, adding new files to a repo without touching existing ones. It is the capability that extends the QA Automation Agent to the API layer, complementing its UI/browser runs with request-context tests.

Its guiding principle: every assertion precise, every test isolated, every failure message meaningful — tests that fail for the right reasons. It reads the repo's structure and conventions, presents a plan before writing, and never modifies an existing file. Coverage spans positive, negative, edge, and chained CRUD cases per endpoint.

Quality

Evaluation criteria

The bar a generated suite must clear before it is trusted.

✓  Named describe blocks and a failure message on every expect.
✓  Secrets sourced from process.env, never hardcoded.
✓  Positive, negative, edge, and chained CRUD coverage per endpoint.
✓  Created test data torn down after each run.
✓  No existing repo file modified — strictly add-only.
