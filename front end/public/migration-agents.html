The agents that migrated Send2

An equivalence-first swarm that reads a legacy Kotlin/XML Android app, extracts its exact behavior, regenerates it as Jetpack Compose + MVVM, and then proves — screen by screen — that nothing changed.

Engine  Claude Code CLI Pipeline  32 stages Shared state  Migration Knowledge Base

Overview

How the swarm is wired

The migration is not one model call — it is a pipeline of specialized, single-purpose agents. Each agent receives the previous agents' outputs plus a slice of shared memory, does one job, and writes a structured result back. Every agent obeys the same overriding constraint: preserve exact legacy behavior before any enhancement.

Agents communicate through a hybrid Migration Knowledge Base (document + retrieval + graph links) appended to every prompt. Downstream agents raise upstream feedback requests when logic is unclear; the Feedback Loop agent routes them back to the knowledge owner. Human-in-the-loop gates sit between phases. Work-unit complexity drives the model tier — low→fast, medium→balanced, high→deep.

Operating principles

The rules every agent works by

Equivalence before enhancement

If a behavior exists in the legacy app, implement it exactly. If it doesn't exist, never add it.

No silent guessing

Uncertainty is documented and routed upstream for a human — never resolved quietly inside an agent.

Only legacy evidence counts

"It makes sense to add" is not a valid reason. "The legacy app does it" is the only valid reason.

Engine & runtime

How the agents actually run

Every agent is a prompt executed through one shared runtime — there are no Semantic-Kernel plugins or skills; the swarm is pure prompt-chained agents over a shared knowledge base.

Backend
claude_code (Claude Code CLI) · or anthropic_api (Semantic Kernel invoke_prompt)
CLI invocation
claude -p --output-format stream-json --max-turns N --permission-mode …
Model
Configurable via --claude-model · tiered by MWU complexity (fast / balanced / deep)
Timeout
1800s (30 min) per invocation · auto prompt-reduction on overflow
Shared state
MigrationKnowledgeBase — hybrid document + retrieval + graph memory
