Overview

What it does

Given a frontend codebase — React/TypeScript SPAs, Vite builds, nginx and Docker deployments — the Web Application Security skill tests for vulnerabilities including SQLi, XSS, command injection, JWT attacks, SSRF, file uploads, XXE, and API flaws as they surface in the browser layer. It's used by the API Security Skill when scope expands beyond endpoints to the frontend that consumes them, and by the Static Analysis Skill to cross-validate Semgrep findings against known frontend vulnerability patterns.

Its guiding principle: test web applications for vulnerabilities including SQLi, XSS, command injection, JWT attacks, SSRF, file uploads, XXE, and API flaws. Findings are grounded in real, same-origin exploitability — not theoretical risk.

Capabilities

What it produces

/ xss

XSS & DOM injection

Reflected, stored, and DOM-based XSS, including dangerouslySetInnerHTML usage.

/ storage

Insecure storage

Session tokens and role data in localStorage, accessible to any same-origin script.

/ auth

Client-side auth bypass

Mock authentication in production code and role escalation via storage tampering.

/ secrets

Exposed secrets in bundles

API keys embedded in Vite define blocks or VITE_ env vars, readable from DevTools.

/ api-flaws

SSRF · file upload · XXE

Browser-adjacent API flaws that surface through the frontend's request layer.

/ crossref

localStorage/JWT cross-ref (flagged)

Cross-references frontend state with API-layer JWT findings, flagged for escalation.

Quality

Evaluation criteria

The bar a finding must clear before it is trusted.

✓  XSS findings tied to an actual injection vector, not a lint-level pattern.
✓  Storage findings checked for same-origin script accessibility.
✓  Mock authentication confirmed active outside dev-only code paths.
✓  Bundle secrets verified as compiled into client-readable output.
✓  Frontend findings cross-referenced with API-layer results where relevant.
