Overview

What it does

Given a raw finding from any source, the OWASP Security skill classifies and prioritizes it against the shared security framework — OWASP Top 10:2025, ASVS 5.0, LLM Top 10 (2025), and Agentic AI Security (2026). It is the common classification layer both the API Security Skill and the Static Analysis Skill reach for before writing a finding report.

Its guiding principle: every finding maps to an OWASP category and CWE — no unclassified vulnerabilities, no vague severity ratings. Severity and priority are standardised across Critical / High / Medium / Low with P0–P3 Jira mapping, so findings stay comparable across audits and sessions.

Quality

Evaluation criteria

The bar a classified finding must clear before it is trusted.

✓  Every finding mapped to an OWASP Top 10:2025 category.
✓  Every finding mapped to a CWE reference where applicable.
✓  Severity and Jira priority assigned consistently, not estimated ad hoc.
✓  Fix recommendation grounded in ASVS 5.0 requirements.
✓  No unclassified vulnerability or vague severity rating passed downstream.
